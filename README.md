**Security Log Analyzer** — a Python tool that turns raw authentication logs into SOC-ready investigations.

| | Capability |
|---|---|
| 🚨 | Brute-force &amp; user-enumeration detection, aggregated **per source IP** (not per log line) |
| ⚖️ | Rule-based severity **plus** an explainable 0–100 risk score with full breakdown |
| 🔍 | IOC extraction — IPv4, domains, URLs, MD5 / SHA1 / SHA256, auto-deduplicated |
| 🎯 | MITRE ATT&amp;CK mapping (T1110, T1078) — evidence-backed only, no overclaiming |
| 🖥️ | `rich` terminal dashboard + CSV / JSON export ready for a ticketing pipeline |
