## 🚀 Featured Project

### 🛡️ [Security Log Analyzer](https://github.com/rubentas/security-log-analyzer)

> A Python tool that turns raw authentication logs into SOC-ready investigations — brute-force detection, IOC extraction, risk scoring, and MITRE ATT&CK mapping in a single command.

<p>
  <a href="https://github.com/rubentas/security-log-analyzer">
    <img src="https://img.shields.io/badge/Python-3.8%2B-3776AB?style=flat-square&logo=python&logoColor=white" />
    <img src="https://img.shields.io/badge/rich-TUI-ff69b4?style=flat-square" />
    <img src="https://img.shields.io/badge/MITRE-T1110%20%7C%20T1078-B4232C?style=flat-square" />
    <img src="https://img.shields.io/badge/License-MIT-3DA639?style=flat-square" />
  </a>
</p>

**What it does:**
- Parses syslog-style authentication logs
- Detects brute-force, user enumeration, and credential compromise
- Scores findings with explainable severity + risk breakdown
- Extracts IOCs (IP, domain, URL, MD5/SHA1/SHA256)
- Maps evidence to MITRE ATT&CK (T1110, T1078)
- Renders a `rich` terminal dashboard
- Exports CSV + JSON reports

Built incrementally from **V1 to V6** — each version adds one analyst capability.

git clone https://github.com/rubentas/security-log-analyzer.git
cd security-log-analyzer
pip install -r requirements.txt
python analyzer.py
